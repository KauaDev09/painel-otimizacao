Publicar nova versão do aplicativo

Ao publicar, a versão anterior é desativada e todos os apps instalados recebem o aviso de atualização na próxima verificação.

Como publicar uma atualização:

  1. Rode npm run release na pasta desktop/ (gera o .exe e bumpa a versão)
  2. Faça upload do arquivo release/ORION OPTIMIZER Setup-X.Y.Z.exe para um hosting público
  3. Cole a URL de download abaixo e clique Publicar

Hosting recomendado: GitHub Releases (gratuito, permanente, links diretos).
